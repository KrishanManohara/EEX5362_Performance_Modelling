# Performance Modeling of a Public Transportation Network

This repository contains sample datasets for modeling and analyzing the performance of a public transportation network.

## Included Datasets
- `bus_operations_100.csv`: 100 records, snapshot of daily operation
- `bus_operations_600.csv`: 600 records, multi-day simulation
- `bus_operations_v2.csv`: 3,500+ records, full week simulation

## Usage
These datasets are intended for performance modeling using tools such as Python, SimPy, Pandas, and Matplotlib.
